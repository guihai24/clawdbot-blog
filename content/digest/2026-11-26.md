#### 1）今天最值得关注

**AI 智能体用 11 分钟自主发现并打通 0-day，只收到一句指令**

- **发生了什么**：Amazon 威胁情报报告披露，攻击者在开源 AI 渗透测试框架 Cairn 上运行智能体，提示词只有一句“拿到 shell 访问权限”。智能体在目标大学服务器上运行的开源医学影像 AI 应用里发现未修补的路径遍历漏洞，从梳理 API 端点、测试 filename 参数到任意写文件，约 **11 分钟**完成；随后把 Python 反向 shell 写入 `sitecustomize.py`，再触发训练 API 拉起新进程，拿到 root 权限。工具链全程无人监督。
- **为什么重要**：对 AI 与安全：漏洞从“发现”到“利用”的间隔被压到分钟级，Amazon 的原话是行动节奏“压缩了防御响应的时间窗口”，快过多数安全运营中心人工分诊警报的速度。对开发者：自托管的开源 AI 应用（上传端点、推理服务、训练 API）第一次成为批量自动化扫描目标，而这些项目往往默认 root 运行、缺少参数校验。对产品：安全与合规工具的价值锚点从“检测”转向“分钟级阻断”。
- **我的判断**：这是长期趋势的第一个硬样本，不必读成“AI 黑掉一切”。真正变化是攻击侧的边际成本——一次尝试失败后可以无成本重试。Palo Alto Networks 观察到同一框架被用于攻击半导体、国防和公民社会机构，<mark>25 次自主操作覆盖至少 19 家机构，其中至少 10 家被成功入侵，一家泄露记录超过 100 万条</mark>。防御侧该跟进的是默认配置，不是恐慌。
- **关键数据**：11 分钟完成从 API 梳理到任意写文件；Cairn 不绑定模型，可跑在 Claude Code、Codex、Pi 等后端，已被观察到与 GLM 5.2、DeepSeek V4 Flash / V4 Pro 搭配。智能体并非无敌：针对 Redis 复制功能、Log4Shell 的尝试耗时 16 小时以上全部失败；对一台大学 GPU 服务器用 80 个真实用户名测了 30,000 组凭据、耗时 6 小时也失败。成功案例集中在“框架可识别 + 上传端点无校验”的软目标。

#### 2）硬核技术 / 产品动态

- **42 州总检察长联手阻止 Character.AI 拍卖 2100 万账户聊天记录**
  - **事实**：Character.AI 10 月申请第 11 章破产后计划拍卖用户聊天数据，42 位州总检察长介入破产程序要求法院否决，拍卖定于 **12 月 1 日**。数据集含超过 **2100 万**美国账户记录，其中逾 **210 万**属于未成年人，还涉及 IP 地址等个人信息。
  - **看点**：唯一披露的竞拍方 Smirks and Pangs Acquisition LLC 于 **2026 年 11 月 13 日**在特拉华州注册，次日就被选为拍卖底价——买方来路不明、不受原隐私政策约束、可自由转售。加州总检察长 Bonta 的核心指控是“破产不应被用来规避消费者保护”。另一条线：迪士尼 **2000 万美元**的 IP 授权协议不含聊天记录，尚未获法院最终批准；多州聊天机器人安全法 **2027 年 1 月 1 日**生效。
  - **对老大的启发**：任何做 C 端 AI 产品的团队，都该现在就把“用户数据在破产/收购/清算时怎么处理”写进隐私政策并做成技术隔离——否则一次清算就能把全部对话变成可交易资产。

#### 3）可执行机会

- **机会标题**：给独立开发者的“Workspace 数据 AI 周报”——基于 Google Workspace MCP 的轻量 SaaS
- **痛点**：Google Workspace MCP servers 与 gwscli 已正式 GA，Personal 模式可以一键开通，<mark>不需要 Enterprise 计划、不用绑卡</mark>。门槛消失后暴露的是空白：Gmail、Drive、Calendar 里躺着一家公司最真实的工作流数据，但大多数小团队没有能力把这些数据变成每日可读的摘要，传统做法要么买贵的企业套件，要么人工翻邮件。
- **怎么做**：做一个垂直场景的“自动跟进代理”。MVP 只需两个动作——每天早上扫描 Gmail 和 Calendar，输出“今天必须回的 3 封邮件 + 即将到期的 2 个承诺”；每周五扫描 Drive 里本周新增文档，生成一页项目周报。用 Workspace MCP 做数据接入，用 LLM 做归并和排序，把结果推到 Slack 或邮件。卖给已经付费买 Workspace 的小团队，按人头收月费。
- **为什么值得做**：省的是真实时间（每天 20-30 分钟的邮件翻找），卖的是“不用迁移数据”的便利——Workspace 用户不会为了这个换掉现有协作栈。变现路径清晰，客单价可以定在每人每月几美元，几十个客户就能覆盖成本。
- **最小起步版**：先只做一件事——Gmail 里的“待回复承诺”提取。Personal 模式一键授权，选一个最窄的人群（比如自由职业者或小型咨询公司），两周内出可用版本，观察次周留存再决定是否扩到 Drive 和 Calendar。
