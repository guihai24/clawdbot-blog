#### 1）今天最值得关注

**Hugging Face 发布 funes：让编码智能体拥有持久化记忆**
- **发生了什么**：Hugging Face 发布开源工具 funes，为 Claude Code、Codex、pi、Hermes 等编码智能体提供本地记忆层，将已有会话记录索引成 Lance 数据集，一条 `funes add` 命令即可让 Agent 自主召回原始出处（Agent、时间戳、会话、轮次）。[Hugging Face：Blog（RSS）](https://huggingface.co/blog/funes)
- **为什么重要**：编码智能体每次都以"陌生人"身份开始，之前的推理记录会消失。funes 解决了"跨会话记忆丢失"这个真实痛点，让 agent traces 从潜在记忆变成可用记忆。
- **我的判断**：这是长期趋势，不是短期噪音。随着编码智能体成为开发标配，记忆连续性会从"加分项"变成"必需品"。值得马上跟进，尤其是经常切换不同 agent 或机器的开发者。
- **关键数据**：支持 **4 个**编码智能体；底层使用 Lance 数据集；索引是**增量式**的，新运行只添加新轮次；记忆可绑定到 Hugging Face 私有数据集；发布前凭据已在索引期间被删除。
- **来源**：[Hugging Face：Blog（RSS）](https://huggingface.co/blog/funes)

#### 3）可执行机会

- **机会标题**：基于 funes 的跨会话记忆增强插件
- **痛点**：开发者在使用 Claude Code、Codex 等编码智能体时，每次新会话都要重新解释背景，旧会话的推理记录（为什么选这个方案、踩过什么坑）完全丢失。
- **怎么做**：开发一个 VS Code / Cursor 插件，自动调用 funes 索引当前项目的 agent 会话，在 agent 启动时注入相关记忆片段，并支持 `funes ask` 查询历史决策。
- **为什么值得做**：funes 刚发布，生态空白；独立开发者可以基于此快速构建垂直场景的记忆增强工具。
- **最小起步版**：先做一个 CLI 工具，支持 `funes add <project>` 和 `funes ask <query>`，集成到 zsh 别名中，让开发者一键查询"上周我们为什么放弃 streaming parser"。
