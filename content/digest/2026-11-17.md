#### 1）今天最值得关注

**阿里发布 Qwen4-Max：2.4 万亿参数，每 token 只激活 710 亿**

- **发生了什么**：11 月 16 日，阿里通义千问团队发布 Qwen4 系列首个模型 Qwen4-Max，采用稀疏 MoE 架构，**2.4 万亿骨干参数**、每 token 激活 **710 亿**，另有 328B N-gram Embedding 参数，原生支持视觉理解与 **100 万 token 上下文**。官方内部评估称，相比 Qwen3.8-Max 可减少约 **50% 的 token 用量**，任务成本降低**超 60%**。同日 Arena 榜单显示，Qwen4-Max 以 **+7.5% 净提升** 位列 Agent Arena 总榜第 14，成为排名第一的中国模型。
- **为什么重要**：对 AI 行业，这是"稀疏大模型 + 长上下文 + 低成本"被压到同一条产品线上；对编程与 Agent 场景，1M 上下文的价格门槛在下降，多轮工具调用不必每轮重付上下文；对独立开发者与 SaaS，"整份文件/整个仓库一次性喂进去"终于有可能算出毛利，按次计费的长文档分析不再是亏本生意。
- **我的判断**：这次真正值得记下来的是 <mark>token 用量下降</mark>，不是参数规模——参数是发布会数字，token 效率才直接进你的账单。这是长期趋势，但不是今天就该全量迁移的信号；榜单 +7.5% 也只说明它在 agent 任务上有竞争力，不等于你的场景更好。
- **关键数据**：**2.4T 骨干参数 / 710 亿激活 / 328B N-gram Embedding / 1M token 上下文 / token 用量约降 50% / 任务成本降超 60% / Agent Arena +7.5%、总榜第 14 / Alibaba 为中国实验室第一**

- **OpenAI：1,819 名科学家的真实使用数据，工作耗时约为原来的 1/1.9**
  - **事实**：OpenAI 经济研究团队分析"ChatGPT for Academic Researchers"夏季试点中 **1,819 名科学家的 58 万条消息**，并问卷 251 人：68% 用 ChatGPT 发展研究想法；参与者估计同样质量的工作，没有 AI 要多花 **1.9 倍**时间；98% 预期 AI 会加速本领域发现。
  - **看点**：真实需求不是"帮我写摘要"，而是 **35%** 带着具体问题来、**36%** 带着想法让它改、**23%** 让它直接提研究问题——提问权开始部分外移给模型。
  - **对老大的启发**：服务专业用户时，"给一个标准答案"远不如"给一个能被继续追问的骨架"，因为他们的价值恰恰发生在后续追问里，工具要留出这个接口。

#### 3）可执行机会

- **机会标题**：把 1M 上下文做成"整份文件一次读完"的按次付费分析服务
- **痛点**：律师、投研、财务手上的 PDF 动辄两三百页，切片方案会丢跨章节引用，用贵模型整份喂进去又算不过账。今天这道算术题第一次算得过来：token 用量约降 50%、任务成本降超 60%，长文档可以整份进、整份出。
- **怎么做**：一个上传页 + 一次长上下文调用 + 固定结构的输出：核心结论、关键条款/数字、前后矛盾点、待确认问题清单。按份收费（比如一份年报 / 一份 SaaS 合同 9.9 元起），不做订阅、不做协作、不做知识库。
- **为什么值得做**：单位成本下降直接变成毛利，而不是变成"功能更强"；用户是每年要看几十上百份文件的专业人士，付费理由具体；模型层可替换，不存在被单一供应商锁死。
- **最小起步版**：只做一个垂直品类（建议先选上市公司年报或 SaaS 采购合同，二者都有明确结构），一个网页上传、一个输出模板、人工抽检前 20 份结果，两周内上线收第一批钱，再决定要不要加第二个品类。
