#### 1）今天最值得关注

**[Anthropic 与 Theorem 合作：用 Claude 在汇编级完成 123 个开源库形式化安全证明]**
- **发生了什么**：Anthropic 联手 Theorem，利用 Claude 将 OSS-Fuzz 模糊测试转化为规格说明，对 123 个现实世界开源软件库的 239 个入口点在 RISC-V 汇编代码级别进行了形式化验证，证明了其在输入小于 **64 MB** 时不会触发内存安全错误或断言失败，期间共生成约 **1.8 亿行** Rocq 证明代码。
- **为什么重要**：形式化验证过去需要专家耗费数年（如 seL4 操作系统花费了约 **20 人年**），导致其在实际生产中极难落地。Claude 能够自动化生成大规模形式化证明，意味着开发者未来能以极低成本为关键业务代码获取严苛的数学安全保障。
- **我的判断**：这是 AI 从“概率性生成代码”走向“决定性证明正确”的重要分水岭。虽然目前门槛依然较高，但长期来看，结合形式化验证的 AI 编程工具将彻底改变高可靠性软件（如金融、系统内核、智能合约）的开发范式。
- **关键数据**：覆盖 **123 个**开源库；处理输入上限 **64 MB**；生成约 **1.8 亿行** Rocq 证明代码。
- **来源**：[Anthropic：Research（发表成果 · 网页）](https://www.anthropic.com/research/formal-verification)

**[DeepSeek 开源生产级推理框架 DeepInfer：单集群日处理 155T tokens 创造 2200 万美元收入]**
- **发生了什么**：DeepSeek 正式开源其内部生产级推理框架 DeepInfer（支撑 DeepSeek-V4.1-Flash），支持 NVIDIA 和华为昇腾平台，具备分布式推理、投机解码、SWA Bounded Replay、结构化输出及最高达 **72 小时**的提示词缓存能力。
- **为什么重要**：这是开源社区迎来的重磅“核弹”。DeepInfer 展现了极高的经济效益：单集群处理量达 **155T tokens/天**，创造 **2200 万美元/天** 的收入，推理利润率高达 **~80%**，投资回收期仅为 **81 天**。
- **我的判断**：极致的推理成本优化和开源吞吐性能正在重新定义大模型的商业边界。对于独立开发者和中小 SaaS 而言，利用开源的 DeepInfer 或同类框架在私有或云端部署 SOTA 模型，其边际成本将进一步大幅下降。
- **关键数据**：单集群日吞吐量 **155T tokens**；日收入 **2200 万美元**；推理利润率 **~80%**；投资回收期 **81 天**；输入缓存命中率高达 **96%**。
- **来源**：[Latent Space](https://www.latent.space/p/ainews-deepseek-deepinfer-open-source)

#### 3）可执行机会

- **机会标题**：基于开源推理与缓存技术的低成本 LLM 代理服务封装
- **痛点**：随着 DeepSeek 等高性能推理框架开源，中小型团队和独立开发者虽然能获得极高性价比的算力，但在多租户环境下的 KV 缓存管理、长文本提示词复用和结构化输出上仍缺乏开箱即用的工程封装。
- **怎么做**：基于开源的 DeepInfer 或 vLLM 架构，为特定垂直领域（如开发者代码审查、法律文书解析）开发一套自带高命中率缓存和结构化 Markdown 输出的代理转发网关，帮助客户将 Token 成本再降 50%。
- **为什么值得做**：推理侧利润率空间巨大（头部可达 80% 利润率），帮助企业客户在不更换模型的前提下通过精细化缓存节省账单，具有极强的直接变现空间。
- **最小起步版**：先用开源推理框架搭建一个针对特定 Schema 输出（如将网页抓取结果直接转为结构化 Markdown 供 Agent 读取）的代理 API 服务，跑通缓存命中率和延迟基准。
