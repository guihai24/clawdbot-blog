#### 3）可执行机会

- **机会标题**：把你的旧文章变成一份可复用的"文风 skill"生成器
- **痛点**：所有人都在写"请用简洁专业的语气"这类风格提示词，结果 AI 写出来还是那股味。Every 的 Mike Taylor 从 2020 年试到今年才解决，说明靠描述风格这条路本身走不通——真正有效的是拿你已经发表的文章当测试集。
- **怎么做**：做一个桌面端或 Web 小工具：用户导入 **12-25 篇**已发表文章（同一格式），工具自动把每篇压成只含论点、事实、引用的 plain brief；然后用这些 brief 让目标模型重写，再让一个 judge 模型对比原文和两份改写稿判断"哪份更像原文"，交换顺序再问一次以消除位置偏差；迭代提示词，只保留分数提升的改动，最后在**留出的几篇**上做终测。产出一份可导入 Claude Code / ChatGPT 的 skill 文件。
- **为什么值得做**：写作是最普遍、最愿意付费的 AI 使用场景，而"像不像我写的"是可量化的验收标准——这意味着你能给出效果承诺，而不是卖提示词模板。订阅制或一次性买断都成立，客单价可以撑起独立开发者。
- **最小起步版**：先做单机脚本，支持导入 12 篇文章 + 自动生成 brief + 双盲对比打分，输出一份 Markdown skill 文件。不做账号、不做云端存储，先自己用一周验证分数真的会涨。
